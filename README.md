# pixl-personal-site
This is a page made for pixl as a personal site, this is something I made as a starter project for pixl.

# Description
This project was a simple site which but in the end I decided to change that and add a cool background, this is different to other sites I have created as a lot of the ones ive made before never utilised javascript, however to get the background to work I had to use javascript which was something I never used before, it took a lot of trial and error, looking at different documents and things like that to finally finish the site. Overall im happy with the way it turned out and I think its really cool. I also added a scene for the cards when the project page is loaded also making the cards stand out overall. This site holds information such as the projects I have made as well as ways to contact me. It also has buttons to my repos of my projects and my github repos page.
